# TGSpeed+

自动提升 Telegram 官方 Android 客户端的文件、图片与视频下载速度。基于现代 `libxposed API 102` 构建，无桌面图标、零系统权限、开箱即用。

---

## 功能亮点

- **全场景无感加速**
  自动优化下载分块大小（`1 MiB`）、提升并发请求下限并在多条下载连接间均匀轮转，同时解除客户端本地下载字节预算限制。大文件下载、高清原图加载与视频边下边播全面生效，并自动避开快拍（Story）与服务端限流退避场景。

- **Telegram 原生设置内直达**
  在 **「Telegram 设置 → 数据与存储」** 下方自动挂载 **TGSpeed+** 入口，点击即弹出深浅色自适应底部面板，直观查看运行状态并随时开关底部轻提示；同时也支持从 LSPosed / Vector 模块管理器打开设置页，双端状态实时同步。

- **原生下载图标闪电角标**
  加速就绪时，在首页顶栏右上角下载进度图标与「下载」页搜索栏右侧速度图标上点亮主题自适应的微缩闪电角标，一眼确认加速在线，且完全保留原有点击、长按交互与过渡动画。

- **看视频零打扰轻提示**
  采用触摸穿透的底部磨砂胶囊并自动避让底部导航栏：
  - 自动静默头像、贴纸、语音等小体积资源以及后台视频预加载；
  - 观看视频、全屏预览媒体或处于画中画（PiP）时全程免打扰，打开视频瞬间自动收起提示；
  - 同一文件短时间内不重复打扰，关闭「显示加速提示」开关完全不影响底层下载加速。

- **纯粹轻量**
  零系统权限、无网络遥测、不在系统桌面创建多余图标；仅注入 Telegram 主进程，停用或卸载模块即刻恢复客户端默认行为。

## 环境要求

| 项目 | 要求 |
| --- | --- |
| 框架 | 支持 **libxposed API 102+** 的框架（新版 LSPosed / Vector 等） |
| 支持应用 | Telegram 官方版（`org.telegram.messenger`）与官网直装版（`org.telegram.messenger.web`） |
| 系统版本 | Android 8.0（API 26）及以上 |

---

## 安装与使用

1. 安装 **TGSpeed+** 模块。
2. 在模块管理器中启用 **TGSpeed+**（作用域已预设为上述两个官方 Telegram 客户端）。
3. **强行停止并重新打开 Telegram**，下载加速即刻自动生效。
4. 如需关闭或开启底部提示，可在 **「Telegram 设置 → TGSpeed+」** 或管理器模块设置中直接切换，无需重启应用。

## 常见问题

- **为什么不同文件的最高下载速度不一样？**
  TGSpeed+ 负责解除客户端本地并发、分块与速率预算瓶颈；最终上限仍会受限于你当前的代理/网络链路带宽、文件所在数据中心（DC）以及 Telegram 服务端的连接速率策略。
- **Telegram 更新后显示「当前 Telegram 版本暂未适配」怎么办？**
  模块内置了写前字段安全校验，遇到未知客户端结构变更时会自动跳过写入以保护应用稳定，并在设置面板展开 **「故障排查信息」**，点击一键复制即可保存完整环境快照等待后续版本适配。
